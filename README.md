# literary-letter

帮你写或改写有文艺感的中文私人信件——情书、思念信、安慰信、致谢信、道歉信、告别信等。

写出来的信要像一个真实的人写给特定收信人，而不是一封能发给任何人的漂亮模板。

---

## 适用场景

用户明确说想要文艺感、抒情风格，或者直接调用 `literary-letter` 时触发。

**适合：**
- 情书 / 表白
- 思念 / 想念某人
- 安慰信
- 致谢信
- 道歉信
- 告别信
- 修复关系的信

**不适合：** 普通聊天消息、商务邮件、正式公文。用户只是说"写封信"时不要自动触发。

---

## 使用方式

```text
用 literary-letter 帮我写一封……
```

可以提供的信息：收信人、两人关系、想说的事、大概篇幅、要不要用文艺风格样本。

信息不够时 skill 会简短提问；如果你不想被问，说"直接写"即可。

---

## 细节处理

| 情况 | 处理方式 |
|------|----------|
| 有真实细节 | 只用你确认过的事实，不编造 |
| 暂时没有细节 | 用 `[昵称]` `[共同经历]` 等占位符，方便你之后填写 |
| 允许虚构 | 告诉 skill "可以虚构细节"，它会创作但不会伪装成真实经历 |

---

## 示例

**真实细节写短笺：**
```text
用 literary-letter 写一封 250 字左右的短信给我男友。
提一下他落在我家的那把伞，还有他走后房间里的安静。
不要编其他回忆。
```

**用占位符写道歉信：**
```text
用 literary-letter 写一封 700 字的道歉信。
昵称、那次争吵的具体事情用占位符代替。
```

**改写一封信：**
```text
用 literary-letter 轻度改写下面这封信。保留所有事实和最后一句话，
去掉空洞的文艺腔，节奏改得自然一点。
```

**快速出稿（不提问）：**
```text
用 literary-letter 根据下面的信息直接写一封致谢信，不用问我问题。
```
