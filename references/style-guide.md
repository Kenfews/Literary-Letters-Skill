# 风格指南

## 高优先级原则

1. 写给具体的人，而不是发表一篇关于感情的散文。
2. 让具体细节承载情绪，让修辞服务于意思。
3. 保留自然口语、停顿和轻微的不完美，避免圆滑得像范文。
4. 根据关系和写信目的调整声音，不套用统一的暧昧开场或告白结尾。
5. 不采用总分、总分总或提纲式结构，不先宣布中心思想再逐段论证。

## 声音与展开

从一个具体时刻、眼前事物、自然问候或正在发生的念头进入。让回忆、感受和想说的话通过联想与转折自然推进，不设置“首先、其次、最后”式层级。

可以使用短句、自我打断和少量口语衔接，但不要刻意复制固定口头禅。称呼可以在情绪转折处再次出现，也可以完全不重复；不要把“亲爱的X”当作机械节拍器。

结尾由写信目的决定，可以是一句明确表达、一个具体行动、克制的祝愿、尊重边界的停顿或准确意象。不要为了升华而总结全文。

## 按信件类型调整

- **表白或思念**：可以亲密、暧昧和脆弱，但不施压对方回应。
- **安慰**：允许对方悲伤，提供陪伴，不急于讲道理或强迫积极。
- **致谢或赞美**：用具体事实支撑感谢，不把对方写成救世主。
- **道歉**：尽早承认责任，避免自我辩护，并写出具体改变。
- **关系修复**：表达愿望，同时尊重对方拒绝、沉默或需要时间的权利。
- **告别或怨怼**：可以带刺或克制，但不羞辱、威胁或操控对方。

## 意象与修辞

优先使用双方生活中真实存在的事物。比喻应准确、逻辑自洽，并与当前情绪有关。宁可朴素准确，也不要连续堆砌植物、季节、夜色、异域地名、神话、名人或冷知识。

避免让每段都以大比喻或金句收尾。允许偶尔出现对仗、悖论或华丽句，但不要形成整齐、可复制的通用模板。

## 避免的写法

- 总分式、提纲式、论文式点题和总结升华
- 通用文艺套话、连续口号和机械金句
- 为显得深刻而堆砌典故、陌生地名或抽象判断
- 把对方写成单方面拯救、教育或治愈写信人的人
- 情绪勒索、逼迫回复、逼迫原谅或擅自承诺永远
- 只换近义词，却没有改善事实、节奏和情绪
